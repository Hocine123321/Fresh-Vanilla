# Changelog

All notable changes to Fresh Vanilla are documented here.

## [2.2] - Source repo established

- Imported existing packaged release (`Fresh Vanilla 2.2.mrpack`) into version control.
- Restructured repo into source form: `pack/modrinth.index.json` + `overrides/` instead of a
  single opaque `.mrpack` binary.
- Added `MODLIST.md` (generated from the manifest, 91 mods).
- Added `scripts/build.sh` to rebuild a `.mrpack` from source.
- Target: Minecraft 1.20.1, Fabric Loader 0.16.0.

---

Earlier history predates this repo — see [Modrinth changelog](https://modrinth.com/modpack/fresh_vanilla/changelog)
for prior version notes.
